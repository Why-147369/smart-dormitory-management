# Checklist - 安全性测试验证清单

## 1. 密码安全性测试
- [ ] 密码以加密形式存储（不是明文）
- [ ] 使用 BCrypt 加密算法
- [ ] 密码字段不可逆加密

## 2. 权限测试
- [ ] 学生只能访问学生端功能
- [ ] 宿管员只能访问所管理楼栋数据
- [ ] 管理员可以访问所有功能和数据
- [ ] 未登录用户访问受保护接口返回 401/403
- [ ] 越权访问返回 403 错误

## 3. JWT 令牌安全
- [ ] 有效令牌可以正常访问
- [ ] 过期令牌返回错误
- [ ] 篡改令牌返回错误
- [ ] 令牌包含过期时间
- [ ] 令牌包含签名验证

## 4. 数据安全性
- [ ] 生产环境配置 HTTPS
- [ ] 密码不在接口响应中返回
- [ ] 敏感数据脱敏处理
- [ ] 数据库连接使用安全配置
