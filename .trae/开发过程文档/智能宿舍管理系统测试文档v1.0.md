## 三、问题记录与解决

### 问题1: CORS跨域错误

**问题描述:**
```
Access to fetch at 'http://localhost:8080/api/...' from origin 'null' has been blocked by CORS policy
```

**问题原因:**
- 浏览器直接打开HTML文件时，origin为null
- 后端CORS配置只允许特定的localhost端口

**解决方案:**
修改 `SecurityConfig.java`，添加允许所有来源的CORS配置：
```java
configuration.addAllowedOriginPattern("*");
```

---

### 问题2: 登录密码错误

**问题描述:**
```
❌ 登录失败: 密码错误
```

**问题原因:**
- 首次启动时插入的管理员密码使用了错误的MD5加密方式
- BCrypt加密的密码与实际输入的明文密码不匹配

**解决方案:**
修改 `DataInitializer.java`，在每次启动时清空并重新初始化数据：
```java
adminMapper.delete(null);
managerMapper.delete(null);
// ... 清空其他表
initAdmin();
initManager();
```

---

### 问题3: 编译错误

**问题描述:**
- `JwtAuthenticationFilter` 缺少 `@NonNull` 注解
- `JwtUtil` 使用了旧版JJWT API
- 多个Controller存在未使用的import

**解决方案:**
1. 添加 `@NonNull` 注解到过滤器方法参数
2. 更新JWT版本兼容的API调用方式
3. 清理所有未使用的import

---

### 问题4: 数据初始化错误

**问题描述:**
- `DormitoryManager` 缺少 `buildingId` 字段
- `LoginLog` 实体缺少字段

**解决方案:**
1. 在 `DataInitializer` 中为 `DormitoryManager` 设置 `buildingId`
2. 补全 `LoginLog` 实体的字段定义

---

### 问题5: 测试页面参数与后端不匹配

**问题描述:**
大量接口测试时返回500错误，提示缺少必填字段

**原因分析:**
测试页面的测试数据参数与后端Entity实体字段不一致，主要包括：
- 字段名不同（如 title vs itemName）
- 缺少必填字段（如 studentId、buildingId等）
- 字段类型不对（如 type:"lost" vs type:1）

**已修复的接口参数：**

| 接口 | 原参数 | 修复后参数 |
|------|--------|------------|
| 提交报修 | repairTypeId,description | studentId,typeId,roomId,title,description |
| 开始处理/完成报修 | /status/1 | /start/1, /complete/1?remark=xxx |
| 添加账单 | roomId,year,month,electricity,water | roomId,year,month,electricUsage,waterUsage,electricFee,waterFee,totalFee |
| 申请访客 | studentId,visitTime | studentId,visitorName,gender,phone,visitTime |
| 发布失物 | title,type,lost | publisherId,itemName,type,description,lostPlace |
| 提交检查 | roomId,score | managerId,roomId,score,remark |
| 申请换寝 | studentId,currentRoomId,targetRoomId,reason | studentId,currentRoomId,currentBedId,targetRoomId,targetBedId,changeType,reason |
| 申请退寝 | studentId,roomId,reason | studentId,roomId,bedId,expectedDate,reason |
| 添加宿管 | username,name,gender,phone | username,password,name,gender,phone,buildingId |
| 消息列表/未读数量 | 仅pageNum,pageSize | 需额外userId,userType参数 |

### 问题6: MySQL关键字冲突

**问题描述:**
```
You have an error in your SQL syntax...near ',create_time  FROM civilized_dormitory...
```

**问题原因:**
- `civilized_dormitory` 表的 `rank` 字段是MySQL保留关键字
- MetaObjectHandler尝试自动填充 `updateTime` 字段但表中不存在

**解决方案:**
1. Entity字段使用反引号转义：`@TableField("\`rank\`")`
2. 在数据库中添加 `update_time` 列

---

### 问题7: 空指针异常

**问题描述:**
审批换寝/退寝时报错：
```
Cannot invoke "com.dormitory.entity.Student.setRoomId(java.lang.Long)" because "student" is null
```

**问题原因:**
Controller方法未检查学生/申请是否存在就直接调用setter

**解决方案:**
在 `RoomChangeController.java` 的审批方法中添加空值检查：
```java
RoomChange roomChange = roomChangeMapper.selectById(id);
if (roomChange == null) {
    return Result.error("换寝申请不存在");
}
Student student = studentMapper.selectById(roomChange.getStudentId());
if (student == null) {
    return Result.error("学生不存在");
}
```
