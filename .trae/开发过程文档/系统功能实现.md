# 系统功能实现

本章针对智能宿舍管理系统的三大核心角色——学生、宿管员、系统管理员，详细阐述各角色核心功能的实现思路、技术难点及具体实现方案。

## 一、学生端核心功能实现

学生端主要面向宿舍入住人员，提供日常住宿相关业务的在线办理功能。

### 1.1 登录认证功能

**关键代码思路**

本系统采用JWT（JSON Web Token）实现无状态身份认证。用户登录时，后端验证用户名和密码成功后生成JWT令牌并返回给前端，前端将令牌存储在localStorage中，后续所有请求通过请求头携带该令牌进行身份验证。系统使用Spring Security框架配置JWT过滤器，对每个请求进行Token解析和权限校验，确保只有登录用户才能访问相应资源。用户密码采用BCrypt加密算法单向Hash存储，即使数据库泄露也无法直接获取明文密码。

**技术难点**

Token的有效期管理是首要难点，需要在安全性和用户体验之间取得平衡。密码的安全性也是重要考量，BCrypt的单向加密特性保证了密码安全。前端需要统一处理Token失效后的跳转登录页逻辑。不同角色用户的权限控制需要精确区分。

**如何实现**

后端在登录接口中验证用户名密码后，调用JwtUtil.generateToken()方法生成Token并返回。

Token生成的核心在于将用户ID、用户类型、用户名等信息存入Token的Payload中，并设置过期时间：

```java
// JWT Token生成 - 将用户身份信息存入Token
public String generateToken(Long userId, Integer userType, String username) {
    Map<String, Object> claims = new HashMap<>();
    claims.put("userId", userId);
    claims.put("userType", userType);
    claims.put("username", username);

    return Jwts.builder()
            .claims(claims)
            .subject(String.valueOf(userId))
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + expiration))
            .signWith(getSecretKey())
            .compact();
}
```

### 1.2 在线报修功能

**关键代码思路**

学生可在线提交报修申请，包括选择报修类型、填写故障描述、上传现场照片（最多3张）。报修单提交后进入待处理状态，宿管员接单后状态变更为已接单，维修开始后变更为维修中，维修完成后变更为已完成。学生在维修完成后可对服务进行满意度评价。

**技术难点**

文件上传是主要技术难点，需要限制文件类型和大小，防止恶意上传大文件。报修单的状态流转需要严格控制，确保只有特定角色在特定状态下才能执行相应操作。

**如何实现**

报修状态采用状态机模式管理，通过常量定义各状态：

```java
// 报修状态常量定义
public class Constant {
    public static final int REPAIR_STATUS_PENDING = 0;    // 待处理
    public static final int REPAIR_STATUS_ACCEPTED = 1;   // 已接单
    public static final int REPAIR_STATUS_REPAIRING = 2;  // 维修中
    public static final int REPAIR_STATUS_COMPLETED = 3;   // 已完成
}
```

学生提交报修时，系统自动生成报修编号并设置初始状态为"待处理"：

```java
// 学生提交报修 - 生成报修编号，设置初始状态
@PostMapping("/submit")
public Result<Repair> submit(@RequestBody Repair repair) {
```

### 1.3 智能客服功能（创新功能）

**关键代码思路**

系统提供智能客服和人工客服两种模式。智能客服对接DeepSeek AI接口进行智能问答，人工客服可转接至管理员处理。系统通过会话管理支持多轮对话，存储完整的聊天记录。

**技术难点**

AI接口调用需要处理网络异常和超时情况。会话状态需要准确管理，包括会话创建、消息收发、关闭等。

**如何实现**

本系统的核心创新点在于集成了DeepSeek大语言模型实现智能问答。当用户选择智能客服模式时，系统将用户问题发送给DeepSeek API，获取AI回复后存储到消息表中。

DeepSeek AI调用是本功能的创新核心，使用Java内置的HttpClient发送请求：

```java
// DeepSeek AI调用 - 创新点：集成大语言模型
private String getAIResponse(String question) {
    if (deepseekApiKey == null || deepseekApiKey.isEmpty()) {
        return "AI客服暂时不可用，请稍后再试或选择人工客服。";
    }
    try {
        HttpClient client = HttpClient.newBuilder()
            .connectTimeout(java.time.Duration.ofSeconds(30))
            .build();

        String requestBody = """
            {"model": "deepseek-chat",
             "messages": [{"role": "system", "content": "你是用户的AI助手，请用中文友好地回答用户的问题。"},
                         {"role": "user", "content": "%s"}],
             "temperature": 0.7}
            """.formatted(question);

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.deepseek.com/v1/chat/completions"))
                .header("Content-Type", "application/json")
                .header("Authorization", "Bearer " + deepseekApiKey)
                .POST(HttpRequest.BodyPublishers.ofString(requestBody))
                .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        if (response.statusCode() == 200) {
            return parseAIResponse(response.body());
        }
    } catch (Exception e) {
        return "AI服务暂时不可用，请选择人工客服。";
    }
    return "AI回答生成失败，请选择人工客服。";
}

// 解析AI返回的JSON
private String parseAIResponse(String body) {
    int contentStart = body.indexOf("\"content\":\"");
    if (contentStart == -1) return "AI回答解析失败";
    contentStart += 10;
    String afterContent = body.substring(contentStart);
    int contentEnd = afterContent.indexOf("\"");
    if (contentEnd == -1) return "AI回答解析失败";
    return afterContent.substring(0, contentEnd)
            .replace("\\n", "\n")
            .replace("\\\"", "\"")
            .replace("**", "")
            .trim();
}
```

### 1.4 换寝申请功能

**关键代码思路**

学生可提交换寝申请，选择目标宿舍和床位，填写换寝原因。申请提交后进入待审批状态，由宿管员进行审批。审批通过后系统自动更新床位状态和学生住宿信息，审批拒绝则保持原状态。

**技术难点**

目标床位必须是空闲状态，需要在提交申请时进行校验。换寝涉及bed表、room表和student表的数据更新，需要保证事务一致性。

**如何实现**

换寝申请的核心在于审批通过后的多表联动更新。系统需要同时完成：释放原床位、占用新床位、更新宿舍人数、更新学生住宿信息。

学生提交换寝申请时，自动记录当前宿舍和床位：

```java
// 学生提交换寝申请 - 记录当前住宿信息
@PostMapping("/apply")
public Result<RoomChange> apply(@RequestBody RoomChange roomChange) {
    Student student = studentMapper.selectById(roomChange.getStudentId());
    if (student == null || student.getRoomId() == null) {
        return Result.error("学生未分配宿舍，无法申请换寝");
    }

    roomChange.setCurrentRoomId(student.getRoomId());
    LambdaQueryWrapper<Bed> bedWrapper = new LambdaQueryWrapper<>();
    bedWrapper.eq(Bed::getRoomId, student.getRoomId());
    bedWrapper.eq(Bed::getStudentId, student.getId());
    Bed currentBed = bedMapper.selectOne(bedWrapper);
    if (currentBed != null) {
        roomChange.setCurrentBedId(currentBed.getId());
    }
    roomChange.setStatus(0);  // 待审批
    roomChange.setCreateTime(LocalDateTime.now());
    roomChangeMapper.insert(roomChange);
    return Result.success(roomChange);
}
```

宿管审批通过后，系统自动完成床位和学生信息的联动更新：

```java
// 审批通过 - 多表联动更新（核心业务逻辑）
@PutMapping("/approve/{id}")
public Result<Map<String, Object>> approve(@PathVariable Long id) {
    RoomChange roomChange = roomChangeMapper.selectById(id);
    if (roomChange.getStatus() != 0) {
        return Result.error("该申请已被处理");
    }

    Student student = studentMapper.selectById(roomChange.getStudentId());
    Long oldBedId = roomChange.getCurrentBedId();
    Long oldRoomId = roomChange.getCurrentRoomId();

    // 1. 释放原床位
    if (oldBedId != null) {
        Bed oldBed = bedMapper.selectById(oldBedId);
        if (oldBed != null) {
            oldBed.setStatus(0);  // 空闲
            oldBed.setStudentId(null);
            bedMapper.updateById(oldBed);
        }
        Room oldRoom = roomMapper.selectById(oldRoomId);
        if (oldRoom != null && oldRoom.getCurrentCount() != null) {
            oldRoom.setCurrentCount(oldRoom.getCurrentCount() - 1);
            roomMapper.updateById(oldRoom);
        }
    }

    // 2. 占用新床位
    Long newBedId = roomChange.getTargetBedId();
    Long newRoomId = roomChange.getTargetRoomId();
    Bed newBed = bedMapper.selectById(newBedId);
    Room newRoom = roomMapper.selectById(newRoomId);

    if (newBed == null || newRoom == null) {
        return Result.error("目标宿舍或床位不存在");
    }
    if (newBed.getStatus() != 0) {
        return Result.error("目标床位不可用");
    }

    newBed.setStatus(1);  // 已占用
    newBed.setStudentId(student.getId());
    bedMapper.updateById(newBed);

    newRoom.setCurrentCount((newRoom.getCurrentCount() == null ? 0 : newRoom.getCurrentCount()) + 1);
    roomMapper.updateById(newRoom);

    // 3. 更新学生住宿信息
    student.setBuildingId(newRoom.getBuildingId());
    student.setRoomId(newRoomId);
    student.setBedNumber(newBed.getBedNumber());
    studentMapper.updateById(student);

    // 4. 更新申请状态
    roomChange.setStatus(1);
    roomChange.setApproveTime(LocalDateTime.now());
    roomChangeMapper.updateById(roomChange);

    Map<String, Object> result = new HashMap<>();
    result.put("roomNumber", newRoom.getRoomNumber());
    result.put("bedNumber", newBed.getBedNumber());
    return Result.success(result);
}
```

## 二、宿管端核心功能实现

宿管端主要面向宿舍管理人员，提供楼栋日常管理功能。

### 2.1 打卡管理功能

**关键代码思路**

宿管员可查看负责楼栋所有学生的打卡记录，支持按日期筛选。可查看打卡统计数据，包括应打卡人数、已打卡人数、未打卡人数和打卡率。对学生的补卡申请进行审批操作，审批通过后系统自动补录打卡记录。

**技术难点**

打卡率的实时统计需要高效查询。补卡审批通过后需要在打卡记录表中补录，同时更新补卡申请表的审批状态。

**如何实现**

学生每日打卡时，系统自动判断是否迟到（23:00后为迟到）：

```java
// 学生打卡 - 自动判断是否迟到
@PostMapping("/record")
public Result<CheckIn> record(@RequestParam Long studentId) {
    LocalDate today = LocalDate.now();
    LocalTime now = LocalTime.now();

    // 检查今日是否已打卡
    LambdaQueryWrapper<CheckIn> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(CheckIn::getStudentId, studentId);
    wrapper.eq(CheckIn::getCheckDate, today);
    CheckIn existCheckIn = checkInMapper.selectOne(wrapper);

    if (existCheckIn != null) {
        return Result.error("今日已打卡");
    }

    CheckIn checkIn = new CheckIn();
    checkIn.setStudentId(studentId);
    checkIn.setCheckDate(today);
    checkIn.setCheckTime(now);
    checkIn.setStatus(Constant.CHECK_IN_STATUS_NORMAL);

    // 判断是否迟到（23:00后）
    boolean isLate = now.isAfter(LocalTime.of(23, 0));
    checkIn.setIsLate(isLate ? 1 : 0);

    checkInMapper.insert(checkIn);
    return Result.success(checkIn);
}
```

宿管审批补卡申请时，自动补录打卡记录：

### 2.2 水电费管理功能（创新功能）

**关键代码思路**

宿管员可对负责楼栋的水电费账单进行管理，包括新增账单、编辑账单、删除账单、批量导入等操作。可查看欠费名单，统计用水用电总量和缴费情况。系统支持按宿舍和月份筛选账单。管理员可在后台配置不同类型宿舍（4人间、6人间等）的水电费单价和用量限额。**创新点：水电超限时自动生成预警通知学生。**

**技术难点**

水电费计算需要根据宿舍类型读取对应的单价。批量导入时需要校验数据格式和逻辑正确性。欠费通知需要及时推送给学生。

**如何实现**

系统通过utility_threshold表存储不同宿舍类型的水电费配置，包括单价和限额。新增账单时，系统根据宿舍类型自动读取对应的单价进行计算，并检查是否超限：

```java
// 新增账单 - 根据宿舍类型读取单价计算费用
@PostMapping("/bill")
public Result<Void> addBill(@RequestBody UtilityBill bill) {
    Room room = roomMapper.selectById(bill.getRoomId());
    
    // 根据宿舍类型获取水电费单价和限额
    LambdaQueryWrapper<UtilityThreshold> thresholdWrapper = new LambdaQueryWrapper<>();
    thresholdWrapper.eq(UtilityThreshold::getRoomType, room.getRoomType());
    UtilityThreshold threshold = utilityThresholdMapper.selectOne(thresholdWrapper);
    
    if (threshold != null) {
        // 使用配置的単価计算费用
        if (bill.getElectricUsage() != null && threshold.getElectricPrice() != null) {
            bill.setElectricFee(bill.getElectricUsage().multiply(threshold.getElectricPrice()));
        }
        if (bill.getWaterUsage() != null && threshold.getWaterPrice() != null) {
            bill.setWaterFee(bill.getWaterUsage().multiply(threshold.getWaterPrice()));
        }
    }
    
    if (bill.getElectricFee() == null) bill.setElectricFee(java.math.BigDecimal.ZERO);
    if (bill.getWaterFee() == null) bill.setWaterFee(java.math.BigDecimal.ZERO);
    bill.setTotalFee(bill.getElectricFee().add(bill.getWaterFee()));
    bill.setIsPaid(0);
    utilityBillMapper.insert(bill);

    // 检查是否超限并创建预警
    checkAndCreateWarning(bill, room, threshold);

    return Result.success();
}
```

**创新功能：水电超限自动预警。** 当用水或用电超过该类型宿舍的限额时，系统自动创建预警记录并通知学生：

```java
// 创新功能：水电超限自动预警并通知学生
private void checkAndCreateWarning(UtilityBill bill, Room room, UtilityThreshold threshold) {
    try {
        if (room == null || room.getBuildingId() == null || threshold == null) {
            return;
        }

        // 检查是否超限
        boolean isWaterOver = threshold.getWaterLimit() != null &&
            bill.getWaterUsage() != null &&
            bill.getWaterUsage().compareTo(threshold.getWaterLimit()) > 0;

        boolean isElectricOver = threshold.getElectricLimit() != null &&
            bill.getElectricUsage() != null &&
            bill.getElectricUsage().compareTo(threshold.getElectricLimit()) > 0;

        if (isWaterOver || isElectricOver) {
            // 创建预警记录
            UtilityWarning warning = new UtilityWarning();
            warning.setRoomId(bill.getRoomId());
            warning.setBuildingId(room.getBuildingId());
            warning.setYear(bill.getYear());
            warning.setMonth(bill.getMonth());
            warning.setWaterUsage(bill.getWaterUsage());
            warning.setWaterLimit(threshold.getWaterLimit());
            warning.setElectricUsage(bill.getElectricUsage());
            warning.setElectricLimit(threshold.getElectricLimit());
            warning.setIsWaterOver(isWaterOver ? 1 : 0);
            warning.setIsElectricOver(isElectricOver ? 1 : 0);
            warning.setStatus(0);
            warning.setCreateTime(LocalDateTime.now());
            utilityWarningMapper.insert(warning);

            // 发送消息通知学生
            StringBuilder messageContent = new StringBuilder("本宿舍");
            if (isWaterOver && isElectricOver) {
                messageContent.append("用水用电均超限");
            } else if (isWaterOver) {
                messageContent.append("用水超限");
            } else {
                messageContent.append("用电超限");
            }
            messageContent.append("，请节约使用！");

            // 查找该宿舍所有学生并发送通知
            LambdaQueryWrapper<Student> studentWrapper = new LambdaQueryWrapper<>();
            studentWrapper.eq(Student::getRoomId, bill.getRoomId());
            List<Student> students = studentMapper.selectList(studentWrapper);

            for (Student student : students) {
                Message message = new Message();
                message.setUserId(student.getId());
                message.setUserType(2);
                message.setTitle("水电费超限提醒");
                message.setContent(messageContent.toString());
                message.setIsRead(0);
                message.setCreateTime(LocalDateTime.now());
                messageMapper.insert(message);
            }
        }
    } catch (Exception e) {
        // 忽略异常
    }
}
```

### 2.3 文明宿舍功能

**关键代码思路**

系统根据卫生检查得分自动计算各宿舍的文明宿舍得分和排名。宿管员可查看本楼栋宿舍的得分排名，前三名进行特殊标识展示。系统支持按年份和月份查询历史排名数据。

**技术难点**

得分计算需要定义合理的公式，综合考虑卫生检查得分。排名计算需要按楼栋和时间进行分组排序。

**如何实现**

系统根据卫生检查记录自动计算各宿舍的平均得分，并按得分降序排名：

```java
// 计算得分和排名 - 根据卫生检查记录自动计算
@PostMapping("/calculate")
public Result<Void> calculate(@RequestParam(required = false) Integer year,
                             @RequestParam(required = false) Integer month) {
    LocalDate now = LocalDate.now();
    if (year == null) year = now.getYear();
    if (month == null) month = now.getMonthValue();

    // 1. 筛选当月卫生检查记录
    List<HealthCheck> allChecks = healthCheckMapper.selectList(null);
    Map<Long, List<HealthCheck>> roomChecks = new HashMap<>();
    for (HealthCheck check : allChecks) {
        if (check.getCheckDate() != null &&
            check.getCheckDate().getYear() == year &&
            check.getCheckDate().getMonthValue() == month) {
            roomChecks.computeIfAbsent(check.getRoomId(), k -> new ArrayList<>()).add(check);
        }
    }

    // 2. 计算各宿舍平均分
    for (Map.Entry<Long, List<HealthCheck>> entry : roomChecks.entrySet()) {
        BigDecimal totalScore = BigDecimal.ZERO;
        int checkCount = 0;
        for (HealthCheck check : entry.getValue()) {
            totalScore = totalScore.add(BigDecimal.valueOf(check.getScore()));
            checkCount++;
        }
        BigDecimal avgScore = totalScore.divide(BigDecimal.valueOf(checkCount), 2, RoundingMode.HALF_UP);

        // 保存或更新得分
        LambdaQueryWrapper<CivilizedDormitory> existWrapper = new LambdaQueryWrapper<>();
        existWrapper.eq(CivilizedDormitory::getRoomId, entry.getKey());
        existWrapper.eq(CivilizedDormitory::getYear, year);
        existWrapper.eq(CivilizedDormitory::getMonth, month);
        CivilizedDormitory existing = civilizedDormitoryMapper.selectOne(existWrapper);

        if (existing != null) {
            existing.setTotalScore(avgScore);
            civilizedDormitoryMapper.updateById(existing);
        } else {
            CivilizedDormitory civilized = new CivilizedDormitory();
            civilized.setRoomId(entry.getKey());
            civilized.setYear(year);
            civilized.setMonth(month);
            civilized.setTotalScore(avgScore);
            civilized.setCreateTime(LocalDateTime.now());
            civilizedDormitoryMapper.insert(civilized);
        }
    }

    // 3. 按得分降序排名
    LambdaQueryWrapper<CivilizedDormitory> rankWrapper = new LambdaQueryWrapper<>();
    rankWrapper.eq(CivilizedDormitory::getYear, year);
    rankWrapper.eq(CivilizedDormitory::getMonth, month);
    rankWrapper.orderByDesc(CivilizedDormitory::getTotalScore);
    List<CivilizedDormitory> all = civilizedDormitoryMapper.selectList(rankWrapper);

    int rank = 1;
    for (CivilizedDormitory c : all) {
        c.setRank(rank++);
        civilizedDormitoryMapper.updateById(c);
    }

    return Result.success();
}
```

### 3.2 数据统计导出功能（创新功能）

**关键代码思路**

管理员可查看各类业务统计数据，包括报修统计、打卡统计、水电费统计、文明宿舍排名等。系统支持将数据导出为Excel文件，方便离线分析和存档。**创新点：支持Excel批量导入导出。**

**技术难点**

复杂统计查询的SQL优化是大数据量场景下的主要挑战。Excel导出需要处理大数据量，防止内存溢出。

**如何实现**

数据统计功能通过 StatisticsController 实现，统计各类业务数据并返回给前端展示。系统统计内容主要包括：学生总数、楼栋数、宿舍数、入住率、各楼栋入住情况、报修类型分布等。

统计核心代码：

```java
// StatisticsController.java - 数据统计
@GetMapping
public Result<Map<String, Object>> getStatistics() {
    Map<String, Object> result = new HashMap<>();

    // 统计学生总数
    Long studentCount = studentMapper.selectCount(null);
    result.put("studentCount", studentCount);

    // 统计楼栋数
    Long buildingCount = buildingMapper.selectCount(null);
    result.put("buildingCount", buildingCount);

    // 统计宿舍数
    Long roomCount = roomMapper.selectCount(null);
    result.put("roomCount", roomCount);

    // 计算入住率
    Long totalBeds = bedMapper.selectCount(null);
    Long occupiedBeds = bedMapper.selectCount(new LambdaQueryWrapper<Bed>()
            .isNotNull(Bed::getStudentId));
    double checkInRate = totalBeds > 0 ? (double) occupiedBeds / totalBeds * 100 : 0;
    result.put("checkInRate", Math.round(checkInRate * 100.0) / 100.0);

    // 各楼栋入住情况统计
    List<Map<String, Object>> occupancyList = new ArrayList<>();
    List<Building> buildings = buildingMapper.selectList(null);
    for (Building building : buildings) {
        Map<String, Object> item = new HashMap<>();
        item.put("buildingName", building.getBuildingName());

        LambdaQueryWrapper<Room> roomWrapper = new LambdaQueryWrapper<>();
        roomWrapper.eq(Room::getBuildingId, building.getId());
        List<Room> rooms = roomMapper.selectList(roomWrapper);
        List<Long> roomIds = rooms.stream().map(Room::getId).collect(Collectors.toList());

        item.put("roomCount", rooms.size());

        long occupiedBedCount = 0;
        if (!roomIds.isEmpty()) {
            occupiedBedCount = bedMapper.selectCount(new LambdaQueryWrapper<Bed>()
                    .in(Bed::getRoomId, roomIds)
                    .isNotNull(Bed::getStudentId));
        }

        item.put("occupiedCount", occupiedBedCount);
        occupancyList.add(item);
    }
    result.put("occupancyList", occupancyList);

    // 报修类型分布统计
    List<RepairType> repairTypes = repairTypeMapper.selectList(
            new LambdaQueryWrapper<RepairType>().orderByAsc(RepairType::getSortOrder)
    );
    List<Map<String, Object>> repairTypeList = new ArrayList<>();
    for (RepairType type : repairTypes) {
        Map<String, Object> item = new HashMap<>();
        item.put("name", type.getTypeName());
        Long count = repairMapper.selectCount(new LambdaQueryWrapper<Repair>()
                .eq(Repair::getTypeId, type.getId()));
        item.put("value", count);
        repairTypeList.add(item);
    }
    result.put("repairTypeList", repairTypeList);

    return Result.success(result);
}
```

```java
public Result<String> importExcel(MultipartFile file) throws IOException {
    InputStream inputStream = file.getInputStream();
    Workbook workbook = new XSSFWorkbook(inputStream);
    Sheet sheet = workbook.getSheetAt(0);

    List<Student> students = new ArrayList<>();
    for (int i = 1; i <= sheet.getLastRowNum(); i++) {
        Row row = sheet.getRow(i);
        if (row == null) continue;

        Student student = new Student();
        student.setStudentNumber(getCellValue(row.getCell(0)));
        student.setName(getCellValue(row.getCell(1)));
        String genderStr = getCellValue(row.getCell(2));
        student.setGender("男".equals(genderStr) ? 1 : 0);
        student.setPhone(getCellValue(row.getCell(3)));
        students.add(student);
    }

    studentService.saveBatch(students);
    workbook.close();
    return Result.success("导入成功");
}
```
