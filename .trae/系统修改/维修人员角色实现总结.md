# 维修人员角色功能 — 实现总结

> 完成日期：2026-05-18

## 实现内容

为系统新增第4种角色"维修人员"，具备登录、查看匹配工单、接单、完成维修的完整能力。

---

## 一、数据库改动

**SQL 文件**：`.trae/系统修改/maintenance_person_upgrade.sql`

```sql
-- maintenance_person 表加登录字段
ALTER TABLE maintenance_person ADD COLUMN username VARCHAR(50), password VARCHAR(100), last_login_time DATETIME;

-- repair 表加维修人员关联
ALTER TABLE repair ADD COLUMN maintenance_id BIGINT, accept_time DATETIME;
```

---

## 二、后端改动

### 2.1 常量
- `Constant.java`：新增 `USER_TYPE_MAINTENANCE = 4`

### 2.2 实体
- `MaintenancePerson.java`：新增 `username`、`password`、`lastLoginTime`
- `Repair.java`：新增 `maintenanceId`、`acceptTime`

### 2.3 登录
- `AuthServiceImpl.java`：注入 `MaintenancePersonMapper`，新增 userType=4 登录分支
  - 查 `maintenance_person` 表验证账号密码
  - BCrypt 比对，状态检查，登录日志记录

### 2.4 维修人员自服务接口
- `MaintenancePersonController.java` 新增 4 个接口：

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/maintenance/me` | GET | 获取当前维修人员信息 |
| `/api/maintenance/repairs` | GET | 我的工单列表（类型匹配的未分配工单 + 已分配给我的工单） |
| `/api/maintenance/repair/accept/{id}` | PUT | 接单（status→2，防重复接单） |
| `/api/maintenance/repair/complete/{id}` | PUT | 完成维修（status→3，自动通知学生） |

- 工单匹配逻辑：维修人员 `specialty` 字段（如"水电,门窗"）按逗号分词，匹配报修类型名称（如"水电报修".contains("水电")）
- 管理员新增维修人员时自动 BCrypt 加密密码
- 编辑维修人员时密码留空则不修改

### 2.5 业务逻辑调整
- 报修流程变更：
  - **原**：学生提交 → 宿管接单 → 宿管选维修师傅名字 → 维修
  - **新**：学生提交 → 维修人员看到匹配工单 → 接单 → 维修完成
  - 宿管端只查看状态，不再操作接单/完成

## 四、新业务流程

```
管理员在后台新增维修人员（设账号密码+擅长类型）
  ↓
维修人员登录（userType=4）
  ↓
工作台显示待接单/维修中/已完成统计
  ↓
工单列表自动匹配：只显示本专业范围内的未分配工单
  ↓
接单：点击接单 → status→2，防重复接单
  ↓
完成：点击完成 → status→3，自动通知学生评价
  ↓
宿管端：全程只查看状态，显示维修人员名字
```
