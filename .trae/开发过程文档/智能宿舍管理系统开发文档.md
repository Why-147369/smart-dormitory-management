# 智能宿舍管理系统 - 开发文档

## 一、项目概述

### 1.1 项目简介
智能宿舍管理系统是一个面向高校宿舍管理的数字化平台，为学生、宿管员、管理员三类角色提供便捷的宿舍管理服务。

### 1.2 技术栈
| 层级 | 技术选型 |
|------|----------|
| 后端 | Spring Boot 3.x + MyBatis |
| 数据库 | MySQL 8.0 |
| 安全框架 | Spring Security + JWT |
| 前端 | Vue 3 + Element Plus |
| 构建工具 | Maven / npm |
| 开发环境 | JDK 17+ / Node.js 18.20.4 |

### 1.3 项目结构

### 6.1 统一响应结果类
```java
@Data
public class Result<T> {
    private Integer code;
    private String message;
    private T data;
    
    public static <T> Result<T> success() {
        return success(null);
    }
    
    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.setCode(200);
        result.setMessage("操作成功");
        result.setData(data);
        return result;
    }
    
    public static <T> Result<T> error(String message) {
        Result<T> result = new Result<>();
        result.setCode(500);
        result.setMessage(message);
        return result;
    }
}
```

### 6.2 JWT工具类
```java
@Component
public class JwtUtil {
    @Value("${jwt.secret}")
    private String secret;
    
    public String generateToken(Long userId, Integer userType) {
        return Jwts.builder()
                .setSubject(String.valueOf(userId))
                .claim("userType", userType)
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + 7 * 24 * 60 * 60 * 1000))
                .signWith(SignatureAlgorithm.HS256, secret)
                .compact();
    }
    
    public Long getUserId(String token) {
        return Long.parseLong(Jwts.parser().setSigningKey(secret)
                .parseClaimsJws(token).getBody().getSubject());
    }
}
```

## 八、开发注意事项

### 8.1 安全问题
- 密码必须使用MD5或其他加密方式存储
- Token设置合理的过期时间
- 敏感接口添加权限校验
- 防止SQL注入和XSS攻击

### 8.2 性能优化
- 合理使用数据库索引
- 列表查询使用分页
- 图片等大文件使用CDN或对象存储
- 接口添加缓存注解

### 8.3 代码规范
- Controller层只负责接收请求和返回响应
- 业务逻辑放在Service层
- 数据操作放在Mapper层
- 使用DTO进行数据传输
- 添加完善的注释
