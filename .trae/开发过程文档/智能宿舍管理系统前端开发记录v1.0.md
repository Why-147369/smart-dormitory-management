## 一、开发概述

本次前端开发基于Vue 3 + Element Plus技术栈，参考若依(RuoYi)管理系统的标准架构，为智能宿舍管理系统构建了完整的前端应用。

### 1.1 技术选型

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | ^3.5.25 | 核心框架 |
| Element Plus | ^2.5.0 | UI组件库 |
| Vite | ^5.2.0 | 构建工具 |
| Vue Router | ^4.6.4 | 路由管理 |
| Pinia | ^2.3.1 | 状态管理 |
| Axios | ^1.6.0 | HTTP请求库 |
| ECharts | ^5.4.0 | 图表库 |
| Sass | ^1.97.3 | CSS预处理器 |

### 1.2 解决的技术问题

由于环境Node.js版本为18.20.4，而最新Vite 8需要Node.js 20+，因此：
- 降级使用Vite 5.2.0
- 手动安装esbuild 0.19.12解决依赖问题

## 三、核心功能实现

### 3.1 路由与权限管理

**路由配置** (`src/router/index.js`)：
- 静态路由：登录页
- 动态路由：根据用户角色动态加载
- 路由守卫：检查登录状态和用户权限

**权限控制**：
```javascript
// userType = 1 → 学生端
// userType = 2 → 宿管端
// userType = 3 → 管理员端
```

### 3.2 状态管理

**用户状态** (`src/store/user.js`)：
- token管理：存储在localStorage
- 用户信息：包含userType用于权限判断
- 登出功能：清除所有状态

### 3.3 HTTP请求封装

**请求拦截器** (`src/utils/request.js`)：
- 自动添加Authorization头
- 统一处理Token过期（401跳转登录）

**响应拦截器**：
- 统一错误提示
- 业务错误展示后端消息

### 3.4 登录功能

**登录页面** (`src/views/login/index.vue`)：
- 账号密码登录
- 登录成功后根据userType跳转不同页面
- 错误提示

### 3.5 布局组件

**管理员布局** (`src/views/layout/index.vue`)：
- 左侧导航菜单
- 顶部面包屑和用户信息
- 退出登录功能

**学生端布局** (`src/views/student/layout/index.vue`)：
- 简洁的侧边导航
- 快捷操作入口

**宿管端布局** (`src/views/manager/layout/index.vue`)：
- 类似的布局结构

## 五、Vite配置

```javascript
// vite.config.js
export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src')
    }
  },
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  }
})
```

**配置说明**：
- 端口：5173
- 代理：将 `/api` 转发到后端 `localhost:8080`
- 路径重写：去掉 `/api` 前缀
