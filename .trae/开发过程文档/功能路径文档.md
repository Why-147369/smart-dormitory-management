# 智能宿舍管理系统 - 功能路径文档

## 项目概述

本项目是一个智能宿舍管理系统，采用 **Spring Boot (Java)** 后端 + **Vue 3 (Element Plus)** 前端架构。系统包含三个角色端：
- **管理员端** - 系统超级管理员
- **宿管端** - 宿舍管理员
- **学生端** - 普通学生用户

---

```
│       └── utils/            # 工具类

│   └── src/
│       ├── api/              # API 接口
│       ├── router/           # 路由配置
│       ├── store/            # 状态管理

```

## 五、API 接口汇总

### 认证相关
- `POST /api/auth/login` - 用户登录
- `POST /api/auth/logout` - 用户登出
- `GET /api/auth/info` - 获取当前用户信息

### 楼栋管理
- `GET /api/building/list` - 获取楼栋列表
- `POST /api/building` - 添加楼栋
- `PUT /api/building` - 修改楼栋
- `DELETE /api/building/{id}` - 删除楼栋

### 房间管理
- `GET /api/room/list` - 获取房间列表
- `POST /api/room` - 添加房间
- `PUT /api/room` - 修改房间
- `DELETE /api/room/{id}` - 删除房间

### 学生管理
- `GET /api/student/list` - 获取学生列表
- `POST /api/student` - 添加学生
- `PUT /api/student/update` - 修改学生信息
- `DELETE /api/student/{id}` - 删除学生
- `POST /api/student/import` - 导入学生
- `GET /api/student/export` - 导出学生

### 报修管理
- `GET /api/repair/list` - 获取报修列表
- `POST /api/repair` - 提交报修
- `PUT /api/repair` - 处理报修
- `DELETE /api/repair/{id}` - 删除报修

### 水电费管理
- `GET /api/utility/list` - 获取水电费列表
- `POST /api/utility` - 添加水电费记录
- `GET /api/utility-threshold/warnings` - 获取预警列表

### 卫生检查
- `GET /api/health/list` - 获取检查记录
- `POST /api/health` - 录入检查结果

### 紧急求助
- `GET /api/emergency/list` - 获取求助列表
- `POST /api/emergency` - 发起求助
- `PUT /api/emergency` - 处理求助

### 失物招领
- `GET /api/lost-found/list` - 获取失物列表
- `POST /api/lost-found` - 发布失物
- `PUT /api/lost-found` - 更新状态
- `DELETE /api/lost-found/{id}` - 删除记录

## 七、技术栈

- **框架**: Vue 3
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **网络**: Axios
