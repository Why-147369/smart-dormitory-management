# 智能宿舍管理系统 - 技术介绍文档

## 一、项目概述

智能宿舍管理系统是一个基于前后端分离架构的Web应用系统，采用Vue 3 + Spring Boot + MySQL技术栈开发。系统主要为高校宿舍管理提供信息化解决方案，包含学生管理、宿舍管理、报修管理、水电费管理等功能。

## 三、后端技术详解

### 3.1 Spring Boot 3.2.0

Spring Boot是Spring框架的简化配置版本，通过自动配置和起步依赖，让Java Web开发更加简单高效。

**核心特性：**
- 自动配置：自动配置Spring应用
- 起步依赖：简化Maven依赖管理
- 内嵌服务器：无需部署到外部容器
- 健康检查：内置应用监控

**在本项目中的应用：**
```java
@SpringBootApplication
public class DormitoryApplication {
    public static void main(String[] args) {
        SpringApplication.run(DormitoryApplication.class, args);
    }
}
```

### 3.2 Spring Security

Spring Security是Spring生态中最成熟的安全框架，提供认证和授权功能。

**主要功能：**
- 用户认证：验证用户身份
- 权限控制：控制用户访问权限
- CSRF防护：防止跨站请求伪造
- 密码加密：集成BCrypt加密

**在本项目中的应用：**
```java
.authorizeHttpRequests(auth -> auth
    .requestMatchers("/api/auth/**").permitAll()
    .anyRequest().authenticated()
)
```

### 3.3 JWT（JSON Web Token）

JWT是一种开放标准，用于在各方之间安全地传输JSON格式的信息。

**优势：**
- 无状态：服务端不需要存储Session
- 跨平台：支持多种语言
- 安全性：签名防篡改
- 扩展性：支持水平扩展

**JWT结构：**
```
Header.Payload.Signature
```

**在本项目中的应用：**
```java
// 生成Token
String token = JwtUtil.generateToken(userId, userType);

// 验证Token
String userId = JwtUtil.getUserId(token);
```

### 3.4 MyBatis-Plus

MyBatis-Plus是MyBatis的增强工具，提供强大的CRUD功能。

**核心特性：**
- 通用CRUD：减少70%SQL编写
- 条件构造器：灵活构建查询条件
- 分页插件：内置分页功能
- 自动填充：自动填充创建时间等字段

**在本项目中的应用：**
```java
// 简单查询
studentMapper.selectList(null);

// 条件查询
LambdaQueryWrapper<Student> wrapper = new LambdaQueryWrapper<>();
wrapper.eq(Student::getName, "张三");
studentMapper.selectList(wrapper);

// 分页查询
Page<Student> page = new Page<>(1, 10);
studentMapper.selectPage(page, wrapper);
```

### 3.5 BCrypt密码加密

BCrypt是一种密码哈希算法，被OWASP推荐用于密码存储。

**特性：**
- 单向哈希：无法从密文反推明文
- 盐值机制：每次加密结果不同
- 可调成本：适应不同安全需求

**在本项目中的应用：**
```java
// 密码加密
student.setPassword(passwordEncoder.encode("123456"));

// 密码验证
boolean matches = passwordEncoder.matches(rawPassword, storedPassword);
```

### 3.6 Apache POI

Apache POI是处理Office文档的Java库，支持Excel读写操作。

**在本项目中的应用：**
```java
// 导入Excel
Workbook workbook = new XSSFWorkbook(fileInputStream);
Sheet sheet = workbook.getSheetAt(0);

// 导出Excel
XSSFWorkbook workbook = new XSSFWorkbook();

```

## 四、前端技术详解

### 4.1 Vue 3

Vue 3是渐进式JavaScript框架，采用Composition API提供更好的代码组织方式。

**核心特性：**
- 响应式数据绑定
- 组件化开发
- Composition API
- 更好的TypeScript支持

**在本项目中的应用：**
```javascript
<script setup>
import { ref, computed, onMounted } from 'vue'

const count = ref(0)
const doubleCount = computed(() => count.value * 2)

onMounted(() => {
  console.log('组件已挂载')
})
</script>

<template>
  <div>{{ count }} x 2 = {{ doubleCount }}</div>
</template>
```

### 4.2 Vite

Vite是新一代前端构建工具，利用浏览器原生ES模块实现极速开发体验。

**优势：**
- 极速冷启动：无需打包
- 热模块替换：即时更新
- 按需编译：只编译用到的代码

**配置：**
```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true
      }
    }
  }
})
```

### 4.3 Element Plus

Element Plus是基于Vue 3的桌面端组件库，提供丰富的基础UI组件。

**常用组件：**
- 表格（el-table）
- 表单（el-form）
- 按钮（el-button）
- 对话框（el-dialog）
- 分页（el-pagination）

**在本项目中的应用：**
```vue
<template>
  <el-table :data="tableData" v-loading="loading">
    <el-table-column prop="name" label="姓名" />
    <el-table-column prop="number" label="学号" />
  </el-table>
  
  <el-pagination
    v-model:current-page="pageNum"
    :page-size="pageSize"
    :total="total"
    @current-change="handlePageChange"
  />
</template>
```

### 4.4 Pinia

Pinia是Vue 3的状态管理库，官方推荐用于替代Vuex。

**特性：**
- TypeScript支持
- 极简API
- 模块化设计
- 支持持久化

**在本项目中的应用：**
```javascript
// stores/user.js
import { defineStore } from 'pinia'

export const useUserStore = defineStore('user', {
  state: () => ({
    userInfo: null,
    token: ''
  }),
  actions: {
    setUserInfo(info) {
      this.userInfo = info
    },
    setToken(token) {
      this.token = token
    }
  }
})
```

### 4.5 Vue Router

Vue Router是Vue.js的官方路由管理器。

**在本项目中的应用：**
```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/login/index.vue')
  },
  {
    path: '/admin',
    name: 'Admin',
    meta: { requiresAuth: true },
    component: () => import('@/views/admin/index.vue')
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
```

### 4.6 Axios

Axios是基于Promise的HTTP客户端，用于浏览器和Node.js。

**特性：**
- 请求/响应拦截
- 自动转换JSON
- 支持并发请求
- 错误处理

**在本项目中的应用：**
```javascript
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器
request.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // 处理401未授权
    }
    return Promise.reject(error)
  }
)
```
