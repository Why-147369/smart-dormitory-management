摘 要

当今高校办学规模的逐渐扩大，学生宿舍是学生在校学习、生活的主要场所，学生宿舍的管理效率、服务质量都影响着高校校园管理工作的水平及学生对高校的满意度。

传统学生宿舍管理以人工记录、线下沟通等方式进行；信息不及时，数据统计困难，报修效率低，不能满足现代化高校校园管理的需求，因此，本课题实现了一款以Spring Boot为依托的智能宿舍管理系统，以Spring Boot为后端框架，Vue.js为前端框架，以MySQL为数据存储数据库。

该系统实现了多角色管理，有学生、宿管员、系统管理员三种角色，有登录、在线报修、住宿信息查询、访客预约、失物招领、费用缴纳、数据统计等功能。学生密码用BCrypt加密，AI智能客服全天候服务，实现宿舍管理流程的数字化、规范化、高效化，降低人工干预，提高管理效率，为学生提供便利服务，为高校宿舍管理工作提供科学数据。

**关键词**：智能宿舍管理系统；Spring Boot；Vue.js；多角色管理；数字化校园

**Abstract**

With the gradual expansion of school-running scale in colleges and universities today, student dormitories serve as the main places for students to study and live on campus. The management efficiency and service quality of student dormitories directly affect the level of campus management in colleges and universities as well as students' satisfaction with the institutions.

Traditional student dormitory management relies on manual record-keeping, offline communication and other methods, which suffer from untimely information, difficult data statistics and low maintenance request efficiency, failing to meet the needs of modern college campus management. Therefore, this project has developed an intelligent dormitory management system based on Spring Boot. The system adopts Spring Boot as the back-end framework, Vue.js as the front-end framework, and MySQL as the data storage database.

It implements multi-role management covering three roles: students, dormitory administrators and system administrators, and provides functions including login, online maintenance requests, accommodation information inquiry, visitor appointment, lost and found, fee payment and data statistics. Student passwords are encrypted with BCrypt, and an AI intelligent customer service provides round-the-clock support. The system realizes the digitalization, standardization and high efficiency of dormitory management processes, reduces manual intervention, improves management efficiency, offers convenient services for students, and provides scientific data for college dormitory management.

**1.1** 研究背景及意义

近年我国高等教育发展速度较快，高校的招生规模一直在扩大，学生人数也不断增加，这就给高校的学生宿舍管理工作带来了不小的挑战。

在传统的宿舍管理模式里，宿舍分配、水电费用统计、报修处理还有访客登记这些工作，大多都是靠人工来完成的，不光要花费大量的时间和人力，还容易出现数据录错、信息更新不及时的问题。比如学生提交了报修申请后，需要等管理员线下登记好，再转达给维修人员，维修进度无法实时查看；宿舍的水电费用需要人工上门抄表再核算，漏算、错算的情况也经常出现；学生想查自己的住宿信息、找舍友的联系方式，还得专门跑到管理处去问，特别不方便。这些问题不仅拉低了宿舍管理的工作效率，也让学生的住宿体验打了折扣。

这种情况下，借着信息技术做一套高效、便捷还智能的宿舍管理系统，是宿舍管理的必然趋势。本次设计的就是基于Spring Boot的智能宿舍管理系统，能把宿舍管理的各项业务都转到线上做数字化处理，信息也能实时共享、流转起来，宿舍管理的整体工作效率也能跟着提升。系统还能给学生提供在线报修、费用缴纳、信息查询这些方便的服务，能满足学生的不同需求，也能让学生的校园归属感更强。而且系统运行后会生成各类数据报表，高校管理人员也能拿这些报表做决策参考，助力校园管理向科学化、智能化发展，这套系统的完成，不管是实际使用还是研究方面，都有不小的价值。

**1.2** 国内外研究状况

1.2.1 国内研究现状

国内在宿舍管理系统的基础管理数字化这块，相关研究已经能覆盖到核心的管理流程。能看到早期的研究重点主要放在管理流程的自动化上，像陈柳羽等人[5]就基于Eclipse平台，用Java、JSP技术搭配MVC设计模式，开发出了高校数字化宿舍管理系统，这套系统能实现学生入住、信息查询、数据维护这些基础功能的自动化处理，让宿舍管理从手工操作慢慢转向程序化处理。而郭进等人[6]开发的“一站式”智能宿舍管理系统，通过权限分级的设计，让管理员能对学生信息、入住情况做增删改查，也能完成新生分寝这些核心工作，这套系统还拿到了软件著作权，已经实际投入使用。随着技术的不断更新，基础管理的功能也做得更细致了，霍佳璐等人[14]用Java语言搭配Oracle数据库搭建了系统，从用户、功能和数据处理三个角度优化了需求设计，让管理工作更高效，也能做到数据的实时更新。另外张凯睿[11]用Python语言开发了原型系统，通过优化基础数据结构，实现了住宿信息的快速查找，也优化了账号的安全管理，能有效减少人力方面的成本。

国内在宿舍安全智能化这块的研究，也摸索出了不少把多种技术整合到一起的监测防护方法。像宿舍火灾、违规用电这些安全问题，唐晓玲[4]就用了LabVIEW平台，把多传感器网络、电气参数监测和视频图像分析技术融到一起，搭建了动态的火灾感知体系，这样火灾预警更准，响应速度也能提升。李鹏霞等人[10]以STM32F103Z1T6单片机为核心，整合了烟雾、温湿度、噪声监测的模块，还额外加了智能语音控制功能，把安全监测和日常的便捷服务做了结合。

谈及人员管理的安全，刘幸兴等人[16]设计的查寝管理系统基于ZigBee技术，数据靠无线网络传输，能实时查看学生的就寝情况，一旦有异常就会告警，PC端和手机APP上都能查询。陈斐等人[8]还把CAD矢量图做的数字宿舍地图，跟Wi-Fi热点室内定位技术结合了，能实时跟踪学生的位置，定位精度能到0.56m，这也给查寝、防聚集这些管理工作，提供了精准的数据支持。

国内的宿舍管理系统研究，现在也开始在服务体验上做个性化优化了，能看出来设计时更在意人文关怀和精准服务。郭甲天等人[7]在系统里增加了个性功能—基于MBTI测试的舍友匹配，用决策树算法给学生的人格特质做分类匹配，能减少因为性格不合引发的学生身心问题，也能体现出宿舍管理里的人文关怀。唐瑞明等人[13]是基于微信小程序开发的移动端管理系统，把宿舍报修、预约、卫生打卡、电费查询还有宿舍社交这些功能都整合进去，借着微信用的人多，学生也更愿意用，服务也更便捷了。

在资源管理智能化这块，蒋兴等人[3]专门针对医院宿舍的使用场景，把物联网和大数据分析技术结合起来，搭建了一个一体化的管理平台，既能实现人员的全周期管理、床位的智能调配，还能依靠数据分析来做管理决策，让宿舍的资源配置能跟着实际情况灵活调整优化。黄景福等人[2]的研究也指出，大数据技术在宿舍资源的合理分配中能发挥核心作用，通过收集和分析宿舍相关的各类数据，不光能提高宿舍管理的工作效率，还能有效减少人力方面的成本投入。

在宿舍管理系统的技术架构上，国内研究的技术选择也变得多元化了。早期开发的系统，大多用的是J2EE、SSM这些传统框架，比如王青[17]就基于J2EE四层框架做的系统设计，胡惠娟[18]用的是SSM框架，这样能让系统的可维护性和扩展性都有所提升。

近年来，SpringBoot、VUE这些主流技术慢慢被广泛用到系统开发中，郭甲天等人[7]用的就是SpringBoot+VUE+MyBatis的架构，还结合了数据可视化技术；顾唐杰[15]则是基于SSM框架搭建的平台，实现了硬件数据和云端的交互，这些设计都让系统的灵活性更高，用户用起来的体验也更好。另外像ZigBee[12][16]、LoRaWAN[23]这些无线通信技术的应用，也打破了之前有线网络的限制，能实现数据采集和设备控制的无线化、远程化。

1.2.2 国外研究现状

国外在智能宿舍管理系统的研究上，起步要比国内早不少，依托当地成熟的信息技术产业基础，形成了体系化设计、技术聚焦加场景延伸的研究特点，在管理流程标准化、技术应用精细化还有跨场景融合这些方面，也积累了不少实际的研究经验。

在宿舍管理流程的体系化搭建上，国外的相关研究更注重把全流程管理做到全覆盖，也讲究标准化落地。Ritesh Kumar Bista等人[19]开发的宿舍管理系统就是典型的Web应用，把宿舍分配、等待名单筛选、食堂计费、外出通行证生成还有投诉登记这些管理工作都整合到一起了，实现了管理流程的一体化处理，还会通过邮件把审批结果通知给学生，信息传递的效率也能提上来。JC Obi等人[20]用形式化方法来描述宿舍管理系统的功能和属性，还通过Zed符号和UML序列图，把系统的交互过程直观地展示出来，这也为系统开发的标准化、规范化提供了理论支撑，能看出来国外设计这类系统，对严谨性要求较高。

国外在宿舍管理相关领域的研究工作，大多会对单项技术做针对性钻研，并且更看重技术和实际使用场景的适配性，不会单纯追求技术堆叠。针对高校宿舍里的用电浪费、考勤统计难度大这两类常见问题，GeethaV等人[21]以印度本地教育机构的宿舍为研究载体，搭建了基于物联网的能耗监管与考勤统计系统。学生离校后未关闭电器造成的电量损耗问题，通过这套系统得到了明显缓解，传统摄像头考勤的模式也得到了优化，宿舍整体管理的准确度也随之提升。该系统的能耗监测部分会实时抓取电器的工作数据，云端分析后会对违规用电、异常用电的情况自动预警，也为宿舍的低碳管理提供了对应的技术支撑。

Zhan Fang Chen等人[22]在设计学生宿舍管理系统时，选用了三层架构搭配WCF技术的方案，还借助Web Service技术将开发语言与运行平台分离开来。这样的架构设计，让团队开发时的协作效率有所提升，系统后续的运维工作也更简便，后续想要做跨平台适配或者新增功能，也有了更灵活的基础。不少欧美高校在搭建本校的宿舍管理平台时，也参考了这种架构设计的思路。

国外的相关研究在拓展管理服务边界时，还格外关注多主体配合以及管理模式的创新。Ritesh Kumar Bista等人[19]研发的宿舍管理系统中，加入了家校同步的功能，学生的住宿、出勤以及课程相关情况，都可以一键同步给家长，让学校和家庭共同参与到住宿管理中。该功能在欧美部分寄宿高校投入使用后，学生遵守宿舍管理制度的情况也有了改善。针对学生宿舍的管理工作，美国多数高校会依托线上系统开展工作，同时也会鼓励学生参与到自主管理当中。学生能自己在系统里挑选心仪的宿舍，也能根据自身情况匹配舍友，系统在匹配时会参考不少因素，比如学生所学专业、日常作息习惯，还有个人爱好等。宿舍里的日常小事，一般都由学生身份的住宿管理员RA来处理，学校相关管理部门，只会在遇到棘手的重要问题时出面协调，这样的安排也让整个管理工作有了不同的层级划分。

新加坡的高校在宿舍管理上有着不一样的思路，校方会在管理系统内加入积分相关的设定，这类积分主要和学生参与社团活动的情况挂钩，甚至会直接影响学生的住宿资格。系统会自动完成积分的统计工作，再按照积分情况分配住宿资源，这也让宿舍管理不再只是简单的后勤服务，还能在引导学生全面发展上起到作用。

1.2.3 国内外研究综述

结合国内外研究现状我们可以知道，宿舍管理系统已普遍实现基础业务数字化，并朝着智能化、一体化、平台化的方向发展，但这两者在功能侧重、管理模式还有技术路线上存在明显差异：

国内研究比较贴合本土管理需求，功能全面、流程完整，注重安全管理、多角色协同和生活服务的集成，但是系统同质化比较高，智能化较浅，数据分析与决策支撑能力还比较薄弱。

国外研究架构规范、技术聚焦，在标准化、轻量化、家校协同方面优势显著，但功能设计与我国高校宿舍管理制度不匹配，没办法法直接落地使用。

在人工智能、物联网、大数据等技术推动下，智能宿舍管理系统正朝着前后端分离、多端适配、AI辅助服务、物联网监测、数据可视化决策方向演进。现有研究尚未充分实现学生使用服务、宿管执行任务、管理员统筹数据，在智能客服、费用异常预警、卫生自动评分、一体化交互等贴近实际使用的功能上还有较大完善空间。

1.3 设计目的

国内高校宿舍管理目前存在人员增加、流程繁琐和效率不高等问题，本文设计并开发了一款功能齐全、操作方便且性能稳定的智能宿舍管理系统，该系统使用Spring Boot技术来进行开发。通过系统开发，把传统人工管理模式中的宿舍分配、报修处理、费用统计和访客登记等业务流程进行数字化，减少人工干预，降低管理成本，提高管理工作的效率和准确性，解决信息传递不及时、数据统计繁琐等问题。学校应当以学生的需求作为导向，通过提供在线报修、住宿信息查询、费用缴纳、失物招领等便捷服务，让学生在不需要线下奔波的情况下就可以办理相关事务，并且实时跟踪业务的进度，提高学生的居住体验和满意度。另外，给宿管员提供学生宿舍管理、报修跟踪、访客审批等功能，让其能够及时了解学生住宿情况，进行高效的工作管理，加强和学生的沟通联系。系统管理员可以对学生权限进行管理，对数据进行维护，并且能够进行统计分析，对整个系统进行有效的管控。系统会生成各类数据报表，为高校宿舍管理决策提供科学依据，推动校园管理向科学化和智能化方向发展。同时，本文在研究和实践中，提高Java后端开发、前端交互设计、数据库设计等相关技术的应用能力，给同类系统的开发提供参考。

2 相关理论技术介绍

本文呈现了一个基于Spring Boot的智能宿舍管理系统设计与实现。其前端使用了Vue.js框架，后端借助SpringBoot框架搭建各个功能模块，数据库采用MySQL，用以存储学生信息和基于Java的智能宿舍管理系统相关信息。

以下为本基于Spring Boot的智能宿舍管理系统设计与实现的相关理论技术介绍。

2.1 SpringBoot框架

Spring Boot作为本次智能宿舍管理系统的核心后端框架，省去了传统 Spring 项目繁杂的手动配置工作，依托约定优于配置的特性，大幅精简了配置代码，让开发重心可以放在宿舍管理的业务逻辑实现上。

该框架自带的各类starter组件，可快速对接Spring MVC、MyBatis-Plus、Spring Security等技术，顺利完成前端请求处理、数据操作、身份权限校验等功能集成，有效加快了项目开发进度。同时其内置的Web服务器免去了额外部署环境的麻烦，部署与调试流程更为简便，且框架本身兼容性与扩展性较强，可适配开发、测试等不同运行环境。

在系统实际运行中，Spring Boot承担着请求接收与业务调度的核心工作，针对报修申请、费用缴纳、数据统计等宿舍相关业务，由控制器接收前端指令，经服务层完成逻辑处理后与数据库交互，实现数据的读写操作，为整个系统提供了稳定的后端运行支撑。

2.2 Vue.js框架

本系统前端采用Vue.js开发，它上手便捷、占用资源少，能快速搭建出易用的交互界面。我们在开发时，运用Vue的组件化思路，把登录界面、报修表单、住宿信息查询页等，各自拆成独立的组件，不用重复编写同类代码，也方便团队分工开发。

Vue的双向数据绑定功能很实用，不用手动去操作DOM元素，用户在填写报修信息、提交访客预约申请时，输入的内容能实时同步到数据模型，让前端交互更流畅。除此之外，我们用Vue Router管理前端路由，实现不同功能页面的跳转；搭配Vuex管理全局数据，比如用户登录状态、权限信息等，避免了多组件数据混乱的情况。

基于Vue.js构建的前端界面简洁清晰，能够与Spring Boot后端高效对接，针对学生、宿管员、管理员三类角色提供了对应的操作页面，有效提升了系统的整体使用体验。

2.3 MySQL数据库

本次智能宿舍管理系统的设计与实现，数据存储和管理是很关键的一块。

MySQL是开源的关系型数据库，好处在于不用复杂的配置，占的服务器资源也不多，读写速度较快。对于小型的智能管理系统，用来处理数据是完全够的。系统运行中会产生不少数据，像学生的基本信息，学号、姓名、专业这些，还有宿舍分配的情况，学生报的修，宿舍的水电费明细，还有外来访客的登记信息，这些数据，都是靠MySQL来存和管理的。

MySQL支持很多种数据类型，不同的数据，类型不一样，比如学生学号是字符型，费用是数值型，报修时间是日期型，选对应的类型来存，既能保证数据不乱，也能让查询和读取更快。另外，MySQL支持SQL查询语句，不管是简单的查一个表，还是复杂点的多表一起查，都能实现。比如学生登录后想查自己的报修记录，管理员要统计一段时间的报修情况做报表，这些功能都得靠MySQL的查询功能，也给系统业务实现省了不少事。

宿舍管理系统的话，数据安全和稳定也很重要。它的备份和恢复数据，在设计系统的时候，可以增加定期自动备份的设置。就算出意外，数据也能找回来。还有，系统可能会有多个学生同时登录、操作，比如多人一起查宿舍信息、提交报修，MySQL的并发控制能处理这种情况，不会出现数据乱了、冲突的问题，系统也能稳定运行。

为了让各类数据能有条理地管理，可以根据系统的业务需求，在MySQL里设计了对应的数据表，把这些表之间的关联关系建好。比如学生表，就是存不同角色学生的个人信息的；宿舍表的话，记录每间宿舍的基本配置、谁住里面这些情况；报修表就详细记着每一条报修。通过这些表之间的关联，查数据、统计数据、调用相关数据都能更快，也能给系统各项功能提供可靠的数据支持。

5.1.1 登录认证

如图5-1

**关键代码思路：**

本系统的身份认证，是用JWT令牌做的无状态验证。用户提交登录信息后，后端先校验账号密码，校验通过了就生成JWT令牌，再把令牌返给前端。前端会把这个令牌存在localStorage里，之后用户每次发操作请求，都得在请求头里带上这个令牌。另外还搭了Spring Security框架，配好了对应的过滤器，每次接口收到请求，都会先解析令牌、校验用户权限，只有验证通过的合法用户，才能访问系统里对应的功能。密码这块为了保安全，所有用户密码都是用BCrypt算法加密后存的，数据库里不会留原始明文密码，能提升数据的安全性。

**技术难点：**

实际开发中遇到的问题还挺多的，比如Token的有效期不好把控，要兼顾安全和学生使用的体验；还有前端得处理Token失效后自动跳登录页的逻辑，需要和前端配合调试；另外学生、宿管、管理员的权限要严格区分，避免出现越权访问接口的情况。

**如何实现：**

后端的登录接口完成账号密码验证后，用JwtUtil.generateToken()这个工具方法生成令牌。在生成令牌时，会将用户的ID、角色类型、账号等信息写入Payload载体，同时配置对应的过期时间。

5.1.2 在线报修

如图5-2

**关键代码思路：**

7 结论

传统高校宿舍管理存在流程繁琐、信息滞后、服务响应不及时等问题，为此本文设计并实现了一套基于SpringBoot的智能宿舍管理系统。系统以Java为开发语言，采用SpringBoot+Vue.js前后端分离架构，MySQL存储数据，MyBatis-Plus作为持久层框架，架构简洁稳定，可支撑日常业务高效运行。结合实际管理场景，系统明确学生、宿管员、管理员三类角色需求，设计了登录认证、在线报修、失物招领、住宿查询、床位管理、访客预约、费用缴纳、数据统计等功能，实现了宿舍管理业务的数字化与线上化。

为了保障不同角色访问系统的安全性，本系统用Spring Security做权限管理，搭配JWT令牌完成身份验证和接口访问控制，能有效避免越权操作的情况，让系统的安全性更有保障。

在数据库操作这方面，用MyBatis-Plus简化了基础的CRUD代码编写，减少了重复写SQL的工作，提升了系统和数据交互的效率；同时也集成了Apache POI实现Excel报表导出，方便管理人员对宿舍相关数据做汇总和分析。

经过多场景的测试验证，这套系统的功能是完整的，运行起来也较稳定，界面响应速度也快，在安全性和兼容性上，都能满足高校宿舍管理的日常使用需求。学生能在系统上便捷办理各类宿舍业务，还能实时查看业务进度；宿管员处理各类申请和咨询也更高效；管理员则可以统一管理系统用户和各项业务数据，生成的统计报表也能为宿舍管理的决策提供数据支撑。

这套系统投入使用后，能替代传统线下跑腿、手工登记的管理模式，简化了宿舍管理的整体流程，降低了人力和时间成本，不仅提升了宿舍管理的工作效率和服务质量，也实实在在改善了学生的住宿体验，提高了大家的使用满意度。

目前该系统还有不少可以优化的地方：系统的数据统计分析功能还比较基础，后续可以引入大数据技术，深入挖掘住宿、报修、水电能耗这些数据的价值；现在系统只支持PC端使用，还可以开发对应的小程序或APP，适配移动端的使用需求；也能结合物联网设备，实现水电数据的实时监测和智能控制；同时还需要进一步完善数据加密机制，更好地保护用户的隐私信息。后续我会结合高校宿舍管理的实际需求，持续对系统做迭代优化，提升系统的智能化水平，让它能更好地服务于高校的数字化校园建设。

// 解析AI返回的JSON

private String parseAIResponse(String body) {

int contentStart = body.indexOf("\"content\":\"");

if (contentStart == -1) return "AI回答解析失败";

contentStart += 10;

String afterContent = body.substring(contentStart);

int contentEnd = afterContent.indexOf("\"");

if (contentEnd == -1) return "AI回答解析失败";

return afterContent.substring(0, contentEnd)

.replace("\\n", "\n")

.replace("\\\"", "\"")

.replace("\*\*", "")

.trim();

}

for (HealthCheck check : allChecks) {

check.getCheckDate().getYear() == year &&

}

// 2. 计算各宿舍平均分

for (Map.Entry<Long, List<HealthCheck>> entry : roomChecks.entrySet()) {

BigDecimal totalScore = BigDecimal.ZERO;

int checkCount = 0;

for (HealthCheck check : entry.getValue()) {

totalScore = totalScore.add(BigDecimal.valueOf(check.getScore()));

checkCount++;

}

BigDecimal avgScore = totalScore.divide(BigDecimal.valueOf(checkCount), 2, RoundingMode.HALF\_UP);

.isNotNull(Bed::getStudentId));

item.put("occupiedCount", occupiedBedCount);

}

result.put("occupancyList", occupancyList);
