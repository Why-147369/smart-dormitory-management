# 智能宿舍管理系统前端开发计划文档

## 文档信息
- 项目名称：智能宿舍管理系统前端
- 技术栈：Vue 3 + Element Plus + Vite
- 后端接口：Spring Boot REST API
- 文档版本：v1.0
- 创建日期：2026-02-14

---

## 一、项目概述

### 1.1 开发目标
开发一套类似若依(RuoYi)标准的管理系统前端，实现学生、宿管员、管理员三种角色的完整功能页面。

### 1.2 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      前端项目结构                            │
├─────────────────────────────────────────────────────────────┤
│  dormitory-web/                                             │
│  ├── public/                        # 静态资源               │
│  ├── src/                          # 源代码                  │
│  │   ├── api/                      # API接口封装             │
│  │   ├── assets/                   # 静态资源(图片/样式)      │
│  │   ├── components/               # 公共组件                │
│  │   ├── directives/               # 自定义指令              │
│  │   ├── router/                   # 路由配置                │
│  │   ├── store/                    # 状态管理(Pinia)          │
│  │   ├── utils/                    # 工具函数                │
│  │   ├── views/                    # 页面组件                │
│  │   │   ├── login/                # 登录页                  │
```

```
用户输入账号密码 → 调用登录API → 返回Token和用户信息
→ 存储Token到localStorage → 存储用户信息到Pinia
→ 根据角色跳转到对应首页
```

**权限设计：**
```
userType = 1 → 学生端 (student/*)
userType = 2 → 宿管端 (manager/*)
userType = 3 → 管理员端 (admin/*)
```

## 七、开发注意事项

### 7.1 Token处理
- 登录成功后保存Token到localStorage
- 请求拦截器自动在请求头添加Token
- Token过期时自动跳转登录页

### 7.2 权限控制
- 路由守卫检查用户角色
- 按钮级权限使用v-if或自定义指令
- 接口返回401时跳转登录页

### 7.3 错误处理
- 网络错误统一提示
- 接口业务错误显示后端返回信息
- 全局loading状态管理

### 7.4 代码规范
- 使用Composition API (<script setup>)
- 组件名使用大驼峰
- API方法名使用小驼峰
- 样式使用SCSS或Less
