## 六、启动说明

```bash
# 1. 创建数据库
mysql -u root -p < dormitory_system.sql

# 2. 修改application.yml中的数据库配置

# 3. 启动后端
cd dormitory-admin
mvn spring-boot:run

# 4. 访问测试
# http://localhost:8080
```
