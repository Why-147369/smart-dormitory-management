# 学生端首页重新设计 Spec

## Why
学生端首页目前内容分散，需要滚动才能看完所有内容。用户希望一页就能显示所有内容，且内容布满整页，不要有太多空余。

## What Changes
采用紧凑的网格布局，重新设计首页结构，内容尽量布满整页

## Impact
- Affected code: student/dashboard/index.vue

## MODIFIED Requirements
### Requirement: 首页布局重构
- **布局**: 采用2-3列网格布局，所有内容紧凑排列
- **高度**: 内容尽量布满整个视口，不留太多空白
- **填充策略**: 
  - 扩大各卡片的内容区域
  - 增加更多信息展示
  - 使用更大字体和间距

### 页面结构设计
```
+--------------------------------------------------+
|  欢迎回来，XXX 同学                    2024年xx月xx日 |
+--------------------------------------------------+
|  [今日打卡]  [我的报修]  [水电费:xxx]  [紧急求助]   |
+--------------------------------------------------+
|  宿舍信息                    |  失物招领轮播         |
|  - 楼栋: X号楼              |  [失物] 物品名称     |
|  - 宿舍: XXX                |  类型:电子产品       |
|  - 床位: X                  |  时间:xxx           |
|  - 姓名: XXX                |  地点:xxx           |
|  - 学院: xxx                |  联系方式:xxx       |
|  - 专业: xxx                |  ●○○ (轮播点)       |
+--------------------------------------------------+
|  [立即打卡] [我要报修] [缴水电费] [查看公告]       |
+--------------------------------------------------+
```

### 设计要点
1. 统计卡片改为更紧凑的横向排列，字体更大
2. 宿舍信息和失物招领左右分栏，内容更丰富
3. 快捷操作单独一行
4. 整体高度占满视口
