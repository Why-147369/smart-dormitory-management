# 智能宿舍管理系统

> Smart Dormitory Management System

基于 **Spring Boot + Vue 3** 的前后端分离智能宿舍管理系统。为学生、宿管员、管理员、维修人员四类角色提供宿舍管理全流程数字化服务，涵盖报修、水电费、打卡、换寝、访客、失物招领、AI 客服、文明宿舍评选等功能模块，数据库共 29 张表，后端 28 个 Controller，前端 52 个页面。

---

## 功能详解

### 一、学生端（15 个页面）

| 功能模块 | 说明 |
|---------|------|
| **在线报修** | 选择报修类型（水电/门窗/网络/家具/卫浴），填写故障描述，上传现场照片（最多 4 张）。支持紧急标记（漏水/断电等），工单在宿管端置顶标红。状态机管理（待处理→已接单→维修中→已完成），实时追踪进度。维修完成后可评价满意度（满意/一般/不满意）。宿管接单前可取消报修 |
| **水电费管理** | 查看本月水电用量与费用账单，支持按月筛选历史记录。在线扫码模拟支付（微信/支付宝二选一，15 秒自动确认），查看缴费记录与欠费提醒 |
| **晚归打卡** | 每晚 22:00-23:00 打卡窗口，一键打卡记录时间。自动判断是否迟到。未打卡可提交补卡申请（由宿管审批）。查看打卡率统计与历史记录 |
| **换寝申请** | 选择本楼栋空闲宿舍和床位，填写换寝原因提交申请。查看审批进度。审批通过后系统自动更新床位状态和学生住宿信息 |
| **访客预约** | 填写访客姓名、性别、手机号、来源地、到访时间及目的，提交后推送宿管审批。支持到访前取消预约 |
| **失物招领** | 发布失物/拾物信息（物品名称、时间、地点、描述、联系方式）。所有学生可查看，认领后标记为"已找到" |
| **紧急求助** | 一键发起求助，宿管端弹窗标红提醒（显示学生姓名/楼栋/宿舍）。学生端实时显示求助状态（已发送→已接收→处理中→已解决） |
| **智能客服** | 对接 DeepSeek 大模型实现 24 小时 AI 问答。支持多轮对话，AI 不可用时自动提示转人工客服。管理员端接收人工客服转接 |
| **卫生检查查看** | 查看本宿舍卫生检查打分（1-10 分）、问题描述及现场照片，支持历史查询 |
| **文明宿舍查看** | 查看本栋文明宿舍排行榜（根据卫生检查均分自动排名） |
| **宿舍公约查看** | 查看学校统一的宿舍管理公约、本楼栋特殊规定及违规处罚条例 |
| **系统公告** | 查看管理员发布的所有公告，支持按时间筛选 |
| **消息通知** | 接收报修接单通知、维修完成提醒、水电超限预警、换寝审批结果、卫生检查通知等。支持已读/未读标记 |
| **个人信息管理** | 查看/修改姓名、学院、专业、班级、电话、头像。查看当前住宿信息（楼栋/宿舍/床位/同寝名单） |

### 二、宿管员端（12 个页面）

| 功能模块 | 说明 |
|---------|------|
| **学生管理** | 增删改查本楼栋学生信息，支持按学院/专业/班级/宿舍筛选，导出学生列表到 Excel |
| **床位分配** | 为学生分配宿舍和床位号。支持按班级批量分配或手动指定。床位状态包括：空闲/占用/维修中/损坏待修。分配后自动更新床位状态 |
| **退寝办理** | 处理毕业/退学/休学的退寝手续，录入资产清点结果，释放床位并更新状态 |
| **换寝审批** | 审核学生换寝申请，批准或驳回（需注明原因）。批准后自动触发多表联动更新（释放原床位 + 占用新床位 + 更新学生信息 + 宿舍人数变更） |
| **报修处理** | 查看本楼栋报修列表，紧急工单置顶标红。接单、填写处理备注、转派维修人员、标记完成。状态变更同步推送通知给学生 |
| **卫生检查** | 对学生宿舍卫生打分（1-10 分），拍摄现场照片，记录问题描述。结果同步学生端，作为文明宿舍评选依据，支持历史查询 |
| **水电费管理** | 录入各宿舍本月水电用量（按宿舍录入，系统自动根据宿舍类型计算费用）。支持 Excel 批量导入。查看用水用电统计柱状图和缴费情况扇形图。欠费超过 5 天自动发送催缴通知 |
| **打卡管理** | 设定打卡截止时间，统计本栋当日打卡率及未打卡名单。审批学生补卡申请（通过后自动补录打卡记录）。导出打卡数据到 Excel |
| **访客审批** | 审核学生提交的访客预约申请，批准或驳回，查看历史访客记录 |
| **文明宿舍评选** | 系统根据卫生检查均分自动生成本栋宿舍排名（前 10 名），同步学生端展示 |
| **公告与消息** | 接收系统公告、新报修提醒、换寝申请通知、水电异常预警等 |
| **个人信息** | 修改联系方式、头像，重置登录密码 |

### 三、管理员端（25 个页面）

| 功能模块 | 说明 |
|---------|------|
| **用户管理** | 管理学生、宿管员、维修人员三类账号的增删改查。支持批量导入学生（Excel）。重置密码、启用/禁用账号。学生信息支持按学院/专业/班级/宿舍筛选 |
| **宿舍资源管理** | 维护全校宿舍楼、宿舍、床位数据。设置房间类型（4/6 人间）。床位状态联动更新（学生入住/退寝后自动切换）。支持批量导入导出。查看全校床位使用情况统计 |
| **宿舍调配监管** | 监控各楼栋的寝室分配、退寝、换寝操作记录，查看全校调配记录 |
| **报修类型管理** | 增删改查报修类型（水电/门窗/网络/家具/卫浴等），调整类型排序。学生端报修下拉列表同步更新 |
| **报修全局管理** | 查看全校所有报修单，支持按楼栋/类型/状态/时间多条件筛选。统计各楼栋报修量（柱状图）。导出报修数据到 Excel |
| **公告管理** | 发布/修改/删除系统公告（如寒暑假离校安排、宿舍调整通知、安全提示），支持分类和置顶 |
| **水电阈值配置** | 按宿舍类型（4/6 人间）预设水电用量阈值和单价。超限自动判定为异常，推送预警给对应宿管员。查看全校水电费缴纳与欠费统计 |
| **数据统计** | 统计学生总数、楼栋数、宿舍数、入住率、各楼栋入住情况、报修类型分布。ECharts 可视化展示柱状图和扇形图 |
| **Excel 导入导出** | 学生信息批量导入导出（Apache POI），水电费批量导入，打卡/报修数据导出 |
| **客服聊天管理** | 接收学生人工客服转接，实时回复消息，查看聊天记录 |
| **文明宿舍排行** | 查看全校文明宿舍排行榜，支持导出到 Excel |
| **操作日志** | 查看系统操作日志（操作人/时间/内容/IP）和登录日志 |

### 四、维修人员端（4 个页面）

| 功能模块 | 说明 |
|---------|------|
| **工单查看** | 查看与自己专业类型匹配的已转派工单（如水电维修工只看水电类报修） |
| **工单处理** | 接单 → 标记维修中 → 完成维修，全流程状态更新 |
| **个人信息** | 修改联系方式、头像、重置登录密码 |
| **工单历史** | 查看历史处理的工单记录 |

## 技术架构

```
前端 Vue 3 (5173)    后端 Spring Boot (8080)    数据库 MySQL (3307)
┌────────────────┐   ┌─────────────────────┐   ┌──────────────┐
│ Element Plus   │──▶│ SecurityConfig       │──▶│ student      │
│ Pinia (状态)   │   │ JwtAuthFilter        │   │ repair       │
│ ECharts (图表) │   │ Controllers (×28)    │   │ building     │
│ Axios (请求)   │   │ Mappers (×25)        │   │ ... (29 张表) │
│ Vue Router     │   │ BCrypt + JWT         │   │              │
└────────────────┘   └─────────────────────┘   └──────────────┘
```

### 安全认证
- **密码加密**：BCrypt 单向哈希 + 随机盐值，默认 1024 轮计算，防暴力破解和彩虹表攻击
- **身份认证**：JWT 无状态 Token（7 天有效期），登录后所有请求通过 `Authorization: Bearer <token>` 携带身份信息
- **权限控制**：Spring Security URL 层拦截（`/api/admin/**` 仅管理员可访问） + Controller 数据层过滤（根据 userType 过滤返回数据），双重保障
- **SQL 注入防护**：MyBatis-Plus LambdaQueryWrapper 预编译参数，天然防 SQL 注入
- **XSS 防护**：Vue 3 默认 `{{ }}` 插值 HTML 转义

### 性能优化
- **HikariCP 连接池**：最大 50 连接，目前 Java 性能最高的连接池
- **N+1 查询优化**：学生列表接口从 1501 次数据库查询降到 4 次（`selectBatchIds` + 内存 Map 关联），响应从 2 秒降至 ~50ms
- **Redis 缓存**：学生列表、楼栋列表、房间列表等高频读取数据加 `@Cacheable`，缓存命中后响应 ~60ms
- **前端路由懒加载**：Vue Router 全部使用 `() => import(...)` 动态导入，首屏仅加载当前页面

### 创新功能
- **AI 智能客服**：集成 DeepSeek 大语言模型，`ChatController.java` 通过 Java HttpClient 调用 API，支持多轮对话和会话管理
- **水电超限预警**：按宿舍类型（4/6 人间）配置不同单价和用量限额，超限自动创建预警并推送通知给学生
- **文明宿舍自动排名**：根据卫生检查评分自动计算各宿舍均分并排名
- **换寝多表联动**：审批通过后在一个事务中同步更新 bed（释放+占用）、room（人数±1）、student（住宿信息）三张表
- **维修人员智能匹配**：按报修工种类型自动匹配对应专业的维修师傅

## 快速开始

### 环境要求
| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Node.js | 18+ |
| MySQL | 8.0 |
| Maven | 3.8+ |
| Redis | 7.x（Windows 版可从 https://github.com/tporadowski/redis/releases 下载） |

### 1. 初始化数据库
```bash
# 创建数据库并导入表结构
mysql -u root -p < dormitory_system.sql
```

### 2. 启动 Redis
```bash
redis-server
```
验证：`redis-cli ping` 返回 `PONG`。

### 3. 启动后端
```bash
cd dormitory-admin
# 修改 src/main/resources/application.yml：
#   - spring.datasource.password（MySQL 密码）
#   - deepseek.api-key（DeepSeek API Key，可选，不配则 AI 客服不可用）
#   - spring.redis.host/port（Redis 连接）
mvn spring-boot:run
```
后端默认端口 **8080**。

### 4. 启动前端
```bash
cd dormitory-web
npm install
npm run dev
```
前端默认端口 **5173**，已配置 Vite 代理：`/api` → `http://localhost:8080`。

### 5. 访问系统
打开浏览器访问 `http://localhost:5173`

**默认管理员账号**：
- 用户名：`admin`
- 密码：`123456`

学生和宿管账号通过管理员端添加，维修人员账号通过管理员端"用户管理"添加。

## 数据库表概览

| 分类 | 表名 | 说明 |
|------|------|------|
| 用户 | `student` / `dormitory_manager` / `admin` / `maintenance_person` | 四类角色 |
| 宿舍资源 | `building` → `room` → `bed` | 楼栋→宿舍→床位三级关联 |
| 报修 | `repair` / `repair_type` / `repair_comment` | 报修单 + 类型 + 评价 |
| 水电费 | `utility_bill` / `utility_threshold` | 账单 + 按宿舍类型的单价限额配置 |
| 打卡 | `check_in` / `check_in_apply` / `check_in_setting` | 打卡记录 + 补卡申请 + 设置 |
| 换寝 | `room_change` / `check_out` | 换寝申请 + 退寝 |
| 客服 | `chat_session` / `chat_message` | 会话 + 消息 |
| 访客 | `visitor` | 访客预约 |
| 其他 | `emergency_help` / `lost_and_found` / `health_check` / `notice` / `message` / `civilized_dormitory` / `dormitory_rule` | 紧急求助/失物招领/卫生检查/公告/消息/文明宿舍/宿舍公约 |
| 日志 | `operation_log` / `login_log` | 操作日志 + 登录日志 |
