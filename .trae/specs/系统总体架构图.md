## 2. 三层架构调用关系

```
请求流程：
浏览器 ──HTTP──▶ Controller ──调用──▶ Service ──调用──▶ Mapper ──JDBC──▶ 数据库
              │              │              │
              │              │              │
           接收请求        处理业务       执行SQL
           参数校验        事务管理       CRUD操作
           返回响应        密码加密       
```

## 3. 技术架构

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Vue 3 + Vite | 现代前端框架 |
| UI组件 | Element Plus | PC端UI组件库 |
| 后端框架 | Spring Boot 2.7 | Java企业级框架 |
| 安全框架 | Spring Security | 身份认证和授权 |
| 认证方式 | JWT Token | 无状态令牌认证 |
| 数据访问 | MyBatis-Plus | ORM持久层框架 |
| 数据库 | MySQL 8.0 | 关系型数据库 |
| 开发工具 | IntelliJ IDEA | 后端开发IDE |
| 测试工具 | JMeter | 性能测试工具 |
