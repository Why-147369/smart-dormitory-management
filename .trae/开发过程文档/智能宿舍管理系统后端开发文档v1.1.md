# 智能宿舍管理系统 - 后端开发文档（第一阶段）

## 开发概述

本次开发完成了智能宿舍管理系统的**基础框架搭建**和**核心模块开发**，为后续业务功能完善奠定了坚实基础。

## 一、本次开发内容

### 1.1 项目基础架构

| 项目 | 内容 |
|------|------|
| **项目名称** | dormitory-admin |
| **技术栈** | Spring Boot 3.2 + MyBatis-Plus + MySQL + JWT |
| **端口** | 8080 |
| **包结构** | com.dormitory |

### 1.2 核心配置文件

**pom.xml 主要依赖：**
- Spring Boot Web
- Spring Security
- MyBatis-Plus
- MySQL Driver
- JWT (jjwt 0.12.3)
- Lombok
- FastJSON

**application.yml 配置：**
```yaml
server:
  port: 8080
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/dormitory_system
    username: root
    password: root
jwt:
  secret: dormitory-system-secret-key-2026
  expiration: 604800000
```

## 六、注意事项

1. **数据库配置**：请确保MySQL中已创建`dormitory_system`数据库并导入`dormitory_system.sql`
2. **密码加密**：登录密码使用BCrypt加密存储
3. **JWT Token**：有效期7天，存储在Header的Authorization中
4. **跨域配置**：已配置允许前端localhost:5173和localhost:3000访问

## 七、快速启动

```bash
# 1. 导入数据库
mysql -u root -p < dormitory_system.sql

# 2. 修改配置文件（数据库密码）
# 编辑 application.yml

# 3. 启动项目
cd dormitory-admin
mvn spring-boot:run
```
