# 智能宿舍管理系统功能描述文档

## 文档说明
本文档基于实际代码分析编写，详细描述智能宿舍管理系统的功能实现情况。

---

## 一、系统概述

### 1.1 系统简介
智能宿舍管理系统是一套面向高校宿舍管理的数字化解决方案，采用前后端分离架构实现学生、宿管员、管理员三类角色的信息化管理。

### 1.2 技术架构
- **后端**：Spring Boot + MyBatis-Plus + JDK 17
- **前端**：Vue 3 + Element Plus
- **数据库**：MySQL 8.0
- **认证**：JWT Token

### 1.3 用户角色
| 角色 | 说明 |
|------|------|
| 学生 | 宿舍入住人员，使用学号登录 |
| 宿管员 | 负责楼栋日常管理，使用账号密码登录 |
| 系统管理员 | 系统最高权限，负责全局配置和数据管理 |

## 二、学生端功能

### 2.1 登录功能
- 使用学号和密码登录
- JWT Token 自动续期
- 登录后跳转到个人首页

### 2.2 个人首页（dashboard）
- 展示今日打卡状态（已打卡/未打卡）
- 显示待处理报修数量
- 显示水电费欠费金额
- 展示宿舍基本信息（楼栋、宿舍号、床位号）
- 快捷操作入口：立即打卡、我要报修、缴纳水电费、紧急求助

### 2.3 个人中心（profile）
- 头像上传更换（支持JPG/PNG，2MB限制）
- 个人信息展示：学号、姓名、楼栋、宿舍号、床位号、专业、班级
- 基本信息编辑：姓名、手机号
- 修改密码（原密码验证）

### 2.4 在线报修（repair）
- **提交报修**
  - 选择报修类型（下拉选择）
  - 填写故障描述
  - 选择是否紧急（紧急工单标红）
  - 上传现场照片（最多3张）
- **报修列表**
  - 状态筛选（待处理、已接单、维修中、已完成）
  - 日期范围筛选
- **报修详情**
  - 查看报修单号、状态、处理进度
  - 取消报修（仅待处理状态）
- **报修评价**
  - 对已完成的报修进行满意度评价（满意/一般/不满意）
  - 填写评价内容

### 2.5 打卡功能（checkin）
- 实时时钟显示
- 今日打卡状态显示
- **立即打卡** - 记录打卡时间
- **补打卡申请**
  - 选择补卡日期
  - 填写补卡原因
  - 提交后等待宿管审批
- 打卡历史记录列表
- 补卡申请记录及审批状态查看

### 2.6 水电费查看（utility）
- 当前宿舍信息展示
- **账单列表**
  - 按月份筛选
  - 按缴费状态筛选（已缴/未缴）
- **账单详情**
  - 用水量（吨）、用电量（度）
  - 水费、电费、合计金额
  - 缴费状态
- **在线支付**
  - 选择支付方式（微信/支付宝）
  - 模拟二维码支付（15秒后返回）
  - 支付成功后状态自动更新

### 2.7 卫生检查查看（health）
- 宿舍信息展示
- 卫生检查记录列表
- 得分显示（8分以上绿色、6-8分黄色、6分以下红色）
- 检查备注查看
- 现场照片查看

### 2.8 访客预约（visitor）
- **访客预约**
  - 填写访客姓名、性别、手机号
  - 填写来源地、到访时间、到访目的
  - 提交后推送至宿管端审批
- **预约记录**
  - 查看审批状态（待审批/已通过/已拒绝）
  - 取消预约（仅待审批状态）

### 2.9 换寝申请（room-change）
- 当前宿舍信息展示
- **换寝申请**
  - 选择目标宿舍（排除当前宿舍和已满宿舍）
  - 选择目标床位
  - 填写换寝原因
  - 提交后推送至宿管端审批
- **申请记录**
  - 查看审批进度和结果

### 2.10 紧急求助（emergency）
- 紧急求助表单
- 发送求助内容
- **求助记录列表**
  - 状态显示：已发送、已接收、处理中、已解决
  - 发起时间、处理备注查看

### 2.11 失物招领（lost-found）
- **发布信息**
  - 选择类型：失物/拾物
  - 填写物品名称、类型、时间、地点
  - 填写物品描述、联系方式
  - 物品类型：证件、电子产品、衣物、书籍、钱包、钥匙、其他
- **信息列表**
  - 失物/拾物标签页切换
  - 查看所有发布信息
- **认领操作**
  - 确认物品找到/领走

### 2.12 智能客服（chat）
- **智能客服** - 对接DeepSeek AI
- **人工客服** - 转接管理员
- 消息发送与接收
- 聊天记录展示
- 会话创建与管理

### 2.13 系统公告（announcement）
- 公告列表展示
- 分类筛选：系统通知、宿舍调整、安全提示、寒暑假、其他
- 日期范围筛选
- 置顶标识显示
- 公告详情弹窗查看

### 2.14 宿舍公约（rules）
- 公约列表展示
- 公约详情：标题、内容、发布时间

### 2.15 文明宿舍（civilized）
- 排行榜展示
- 排名、楼栋、宿舍号、得分、月份
- 前三名特殊标识

### 3.9 卫生检查（health）
