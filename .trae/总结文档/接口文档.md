# 宿舍管理系统 API 接口文档

- **基础URL**：`http://localhost:8080`
- **认证方式**：JWT Token（Header: `Authorization: Bearer <token>`）
- **统一响应**：`{ "code": 200, "message": "操作成功", "data": {...} }`

## 附录：关键状态值

**用户类型 (userType)**：1=学生 / 2=宿管 / 3=管理员

**报修状态**：0=待处理 / 1=已接单 / 2=维修中 / 3=已完成 / 4=已取消

**访客/换寝状态**：0=待审批 / 1=已通过 / 2=已拒绝 / 3=已完成 / 4=已取消

**床位状态**：0=空闲 / 1=占用 / 2=维修中 / 3=损坏待修

**打卡**：status 0=补卡 1=正常打卡 / isLate 0=未迟到 1=迟到(23:00后)
