## 一、问题汇总

### 1.1 Vite版本与Node.js版本不兼容

**问题描述**：
- 初始使用Vite 8.x版本，但环境Node.js版本为18.20.4
- Vite 8.x要求Node.js 20.19+ 或 22.12+
- 运行时报错：`Error: VITE v5.2.0 ready in 1036 ms` 后无法启动

**错误信息**：
```
You are using Node.js 18.20.4. Vite requires Node.js version 20.19+ or 22.12+. Please upgrade your Node.js version.
```

**解决方案**：
- 降级Vite到5.2.0版本
- 手动安装esbuild 0.19.12解决依赖问题

**操作命令**：
```bash
npm install vite@5.2.0 @vitejs/plugin-vue@5.0.0 esbuild@0.19.12 --save-dev
```

---

### 1.2 esbuild依赖缺失

**问题描述**：
- 降级Vite后，运行时报错找不到esbuild模块
- 错误信息：`Cannot find package 'esbuild'`

**错误信息**：
```
Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'esbuild' imported from ...\vite\dist\node\cli.js
```

**解决方案**：
- 手动安装esbuild

**操作命令**：
```bash
npm install esbuild@0.19.12 --save-dev
```

---

### 1.3 npm install 安装失败

**问题描述**：
- 尝试重新安装依赖时，npm报错EOVERRIDE
- 原因：package.json中存在overrides配置与直接依赖冲突

**错误信息**：
```
npm error code EOVERRIDE
npm error Override for vite@5 conflicts with direct dependency
```

**解决方案**：
- 删除package.json中的overrides配置
- 清理node_modules和package-lock.json
- 重新执行npm install

**操作步骤**：
1. 修改package.json，删除overrides字段
2. 删除node_modules和package-lock.json
3. 重新安装依赖

---

### 1.4 登录页面代码语法错误

**问题描述**：
- 登录页面代码中出现语法错误
- 错误：使用箭头函数语法错误

**错误代码**：
```javascript
// 错误代码
if (userType === 3) {
  router.push('/dashboard')
} else('/dashboard')
{
  router.push
}
```

**解决方案**：
- 修正为正确的条件语句

**正确代码**：
```javascript
// 正确代码
if (userType === 1) {
  router.push('/student')
} else if (userType === 2) {
  router.push('/manager')
} else {
  router.push('/dashboard')
}
```

**错误代码**：

// 错误代码
const handle) => {

### 1.6 路由空白页问题

**问题描述**：
- 访问 http://localhost:5173/ 时页面完全空白
- 刷新页面后仍然空白

**可能原因**：
1. 路由守卫逻辑问题
2. 根路径 `/` 没有正确匹配到登录页
3. 路由懒加载失败

**解决方案**：
1. 修改路由守卫逻辑，添加对根路径的特殊处理
2. 确保未登录时正确跳转到登录页
3. 重启开发服务器

**修改内容**：
```javascript
// 修改路由守卫
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const userType = localStorage.getItem('userType')
  const roles = to.meta?.roles
  
  if (to.meta.requiresAuth !== false && !token && to.path !== '/login') {
    next('/login')
  } else if (to.path === '/login' && token) {
    // 根据userType跳转
    const userTypeNum = parseInt(userType)
    if (userTypeNum === 1) {
      next('/student/dashboard')
    } else if (userTypeNum === 2) {
      next('/manager/dashboard')
    } else {
      next('/dashboard')
    }
  } else if (to.path === '/' && token) {
    // 根路径特殊处理
    const userTypeNum = parseInt(userType)
    if (userTypeNum === 1) {
      next('/student/dashboard')
    } else if (userTypeNum === 2) {
      next('/manager/dashboard')
    } else {
      next('/dashboard')
    }
  } else {
    next()
  }
})
```

## 二、问题预防建议

### 2.1 Node.js版本管理

- 开发前确认项目要求的Node.js版本
- 建议使用nvm或nvm-windows管理Node.js版本
- 在package.json中注明engines要求

### 2.2 代码编写规范

- 使用IDE的语法检查功能
- 编写完成后进行代码审查
- 避免复制粘贴导致的语法错误

### 2.3 依赖管理

- 了解package.json中各字段的作用
- 避免使用overrides导致依赖冲突
- 安装依赖时注意版本兼容性

- 开发完成后进行功能测试
- 刷新页面测试路由是否正常
